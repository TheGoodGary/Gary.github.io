Hola, esto esta hecho para las personas que no podemos entender el lenguaje de señas, esto es un "traductor" el cual dirá cada letra que nostros queramos que entiendan.

_¿Cómo funciona?_
.
Este proyecto funciona mediante un lenguaje de señas (ASL) donde ustedes tendrán que hacer con sus manos ciertas "señas" las cuales el programa podrá reconocer y darnos la letra deseada y así formar palabras poco a poco.
